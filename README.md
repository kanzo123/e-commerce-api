# E-Commerce API

A REST API for an e-commerce store built with Node.js, Express and MongoDB.

## Tech
- Node.js + Express
- MongoDB (Mongoose)
- JWT auth (access + refresh tokens)
- Multer + Cloudinary for product images

## Getting started
1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env` and fill in values
4. `npm run dev`
